WHAT THE BOT DOES
Every 5 minutes it checks the price of the coin I pick (Bitcoin unless I say otherwise; Ethereum, Solana or gold through PAXG work too). When it moves 2% or more in an hour, it sends me one Telegram message with:
1. How far it moved and the price now.
2. The top 3 headlines about that coin from the last two hours, with links.
3. One line from an AI on which headline most likely explains the move, or that none of them do.
4. What happened before: over the last 12 months, how many hours moved this much in the same direction, and how many times it was up or down 24 hours later.
It never trades. It only reads prices and news, and it never holds a key to an exchange account.

HOW TO BUILD IT (for you, the coach)
- Python 3, standard library only, one file called bot.py.
- Prices: Coinbase's free public price data (api.exchange.coinbase.com candles for the COIN setting, for example BTC-USD). No key needed. Use 5 minute candles for the last hour and 1 hour candles for the 12 month history (300 per request, so page back through it).
- Count one big move as one sample: after a match, skip ahead 24 hours.
- News: these free feeds, no key needed. Keep items from the last two hours whose title mentions the NEWS_WORD setting (for example bitcoin), and drop repeats. For the Google News feed, search for the NEWS_WORD instead of bitcoin.
  https://www.coindesk.com/arc/outboundfeeds/rss/
  https://cointelegraph.com/rss
  https://decrypt.co/feed
  https://news.google.com/rss/search?q=bitcoin+when:2h&hl=en-US&gl=US&ceid=US:en
- The AI line: use whichever key I have, OpenAI or Anthropic. Tell it not to predict prices or say buy or sell. If the AI call fails, send the alert without that line.
- Only one alert per direction every two hours, so one big move does not send twelve messages.
- If a feed or the price check fails, skip it and try again next time. Never crash.
- End every alert with: "History, not a prediction."
- It runs forever, checking every 5 minutes, and prints one line to the log each check.
- When the setting SEND_TEST_ON_START is "yes", it sends one alert as soon as it starts, whatever the move, so I can see it works.
- Settings come only from environment variables: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, COIN (default BTC-USD), NEWS_WORD (default bitcoin), MOVE_PCT (default 2), SEND_TEST_ON_START, and OPENAI_API_KEY or ANTHROPIC_API_KEY. Nothing secret is ever written in the code.
- Give me the whole file in one code block, ready to paste.
