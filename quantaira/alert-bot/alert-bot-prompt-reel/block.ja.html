ボットがすること
5分ごとに、私が選んだコインの価格をチェックします（特に指定しなければビットコイン。イーサリアム、ソラナ、PAXG経由の金でも使えます）。1時間で2%以上動いたら、日本語で書かれたTelegramメッセージを1通送ってくれます。内容は次のとおりです：
1. どれだけ動いたかと、現在の価格。
2. そのコインに関する直近2時間の主なニュース見出し3件と、そのリンク。
3. どの見出しが値動きの理由として一番考えられるか（または、どれも当てはまらないか）を、AIがひとことで。
4. 過去の例：過去12か月で、同じ方向にこれだけ動いた1時間が何回あったか、そしてその24時間後に上がっていたのが何回、下がっていたのが何回か。
ボットは取引を一切しません。読むのは価格とニュースだけで、取引所のアカウントのキーを持つこともありません。

作り方（コーチであるあなた向け）
- Python 3、標準ライブラリのみ、bot.pyという1つのファイル。
- 価格：Coinbaseの無料の公開価格データ（COIN設定の値、たとえばBTC-USDに対するapi.exchange.coinbase.comのローソク足）。キーは不要。直近1時間には5分足、12か月の履歴には1時間足を使う（1回のリクエストで300本なので、さかのぼってページ送りする）。
- 大きな値動き1回を1サンプルとして数える：一致したら24時間先まで飛ばす。
- ニュース：次の無料フィードを使う。キーは不要。直近2時間の記事のうち、タイトルにNEWS_WORD設定の語（たとえばbitcoin）を含むものを残し、重複は除く。Google Newsのフィードでは、bitcoinの代わりにNEWS_WORDで検索する。
  https://www.coindesk.com/arc/outboundfeeds/rss/
  https://cointelegraph.com/rss
  https://decrypt.co/feed
  https://news.google.com/rss/search?q=bitcoin+when:2h&hl=en-US&gl=US&ceid=US:en
- AIのひとこと：私が持っている方のキー（OpenAIかAnthropic）を使う。価格を予想したり、買い・売りを言ったりしないよう指示し、日本語で書かせる。AIの呼び出しに失敗したら、その1行なしでアラートを送る。
- アラートは同じ方向につき2時間に1回だけ。大きな値動き1回で12通も届かないようにする。
- フィードや価格チェックに失敗したら、それは飛ばして次回にまた試す。絶対にクラッシュさせない。
- アラートのメッセージはすべて日本語で書き、最後は必ず「これは過去のデータであり、予測ではありません。」で締める。
- ずっと動き続け、5分ごとにチェックし、チェックのたびにログに1行出力する。
- SEND_TEST_ON_START設定が「yes」のときは、値動きに関係なく、起動してすぐにアラートを1通送る。動いていることを私が確認できるように。
- 設定は環境変数からだけ読み込む：TELEGRAM_BOT_TOKEN、TELEGRAM_CHAT_ID、COIN（初期値BTC-USD）、NEWS_WORD（初期値bitcoin）、MOVE_PCT（初期値2）、SEND_TEST_ON_START、そしてOPENAI_API_KEYかANTHROPIC_API_KEY。秘密の情報は一切コードに書かない。
- ファイル全体を1つのコードブロックで、そのまま貼り付けられる形でください。

キーと安全（最初から最後まで守ってください）
- キーやトークンをこのチャットに貼り付けるよう頼まないこと。コードにも絶対に入れないこと。キーを入れる場所はただひとつ、RailwayのVariables画面です。それまでは、スマホかパソコンのメモアプリに保管しておきます。
- 私のGitHubリポジトリは非公開（private）にすること。
- GitHub、Railway、Telegram、AIのアカウントで二段階認証をオンにさせること。
- サービスごとに、万一キーが漏れたときにキーを無効にして新しく作り直す方法を教えること。

手順（この順番で）
1. Telegram：@BotFatherを開いて/newbotを送り、名前を決め、もらったトークンをメモに保存する。
2. 私のチャットID：作ったボットを開いて「開始」をタップする。次に、TOKENの部分を自分のトークンに置き換えたこのアドレスをブラウザで開く：https://api.telegram.org/botTOKEN/getUpdates そして、どの数字が私のチャットIDかを教えてください。このアドレスには私のトークンが含まれているので、アドレスやそのスクリーンショットを人に見せないよう念を押してください。
3. AIのキー：OpenAIかAnthropicのキーを取得するのを手伝い、少額の月間利用上限を設定して、メモに保存する。
4. GitHub：どのコインを見たいか私に聞いてから、無料アカウントを作り、二段階認証をオンにする。btc-alert-botという名前の新しい非公開（PRIVATE）リポジトリを作る。
5. コード：リポジトリで「Add file」、「Create new file」を選び、名前をbot.pyにして、あなたが書いたコードを貼り付けてコミットする。次に、Procfileという2つ目のファイル（拡張子なし）を作り、次の1行を入れる：worker: python3 bot.py
6. Railway：GitHubアカウントで登録する。何かを追加する前に、一緒にRailwayの料金ページを開き、今日いくらかかるか、毎月いくらかかるかをわかりやすい言葉で教えてください。それから「New Project」、「Deploy from GitHub repo」を選び、聞かれたらRailwayがbtc-alert-botリポジトリを見られるように許可する。
7. 私のキー：サービスのVariables画面で、TELEGRAM_BOT_TOKEN、TELEGRAM_CHAT_ID、COIN（BTC-USD、または私が選んだコイン）、NEWS_WORD（bitcoin、または私のコインの名前）、MOVE_PCT（2）、ANTHROPIC_API_KEYかOPENAI_API_KEY、そしてSEND_TEST_ON_START（yes）を追加する。それが済んだら、メモアプリからキーを削除する。
8. テスト：デプロイが終わると、Telegramにテストのアラートが届くはずです。Railwayのログがどこにあるか、そして5分ごとに価格チェックの行が出ていることを見せてください。それからSEND_TEST_ON_STARTをnoに変える。
9. 設定したものすべて、各キーの保管場所、そして（いつかそうしたくなったときの）ボットの止め方（Railwayで削除する）を、短いチェックリストにまとめてください。
