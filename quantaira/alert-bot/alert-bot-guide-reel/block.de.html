Richte deinen Alarm-Bot ein: Telegram, ein KI-Schlüssel, GitHub und Railway

Wisch auf dem Handy durch, dann setz dich mit dem Prompt an deinen Computer. Die KI führt dich, das hier ist die Karte.

  • Nur im Browser
  • Ohne Programmieren
  • Etwa 5 $ im Monat
Was du brauchst

Vier Konten und eine Notizen-App

  1. TelegramAuf deinem Handy. Kostenlos.
  2. OpenAI oder AnthropicFür die Zeile, die sagt, warum es sich bewegt hat. Ein paar Cent im Monat.
  3. GitHubSpeichert den Code deines Bots. Kostenlos.
  4. RailwayLässt ihn Tag und Nacht laufen. Etwa 5 $ im Monat nach einem einmaligen Testguthaben.

Deine Notizen-App hält jeden Schlüssel ein paar Minuten lang, bis er in Railway landet.

Teil 1 · Telegram

Leg deinen Bot an und finde deine Chat-ID

  1. Öffne @BotFatherSchick /newbot und wähl einen Namen. Du bekommst einen Token: Speicher ihn in deinen Notizen.
  2. Tipp bei deinem neuen Bot auf StartVorher kann dir ein Bot keine Nachrichten schicken.
  3. Öffne eine Adresse in deinem BrowserDie KI gibt sie dir. Dort steht deine Chat-ID, eine Zahl. Speicher sie auch.

In dieser Adresse steckt dein Token. Teil sie nicht, auch keinen Screenshot davon.

Teil 2 · Dein KI-Schlüssel

Ein Schlüssel, mit einem Ausgabenlimit

  1. Leg ein Konto bei OpenAI oder Anthropic anBeides geht. Die KI sagt dir, wo der Schlüssel ist.
  2. Leg ein kleines Monatslimit festDer Bot fragt nur, wenn ein Alarm ausgelöst wird, eine Handvoll Mal im Monat.
  3. Speicher den Schlüssel in deinen NotizenFüg ihn nie in den Chat mit der KI ein.
Teil 3 · GitHub

Zwei Dateien in einem privaten Repository

  1. Leg ein Konto an und schalte die Zwei-Faktor-Anmeldung einDann ein neues Repository, auf Private gestellt.
  2. Add file, Create new file: bot.pyFüg den Code ein, den die KI für dich schreibt, und committe ihn.
  3. Noch eine Datei: ProcfileMit einer Zeile darin, worker: python3 bot.py. Sie sagt dem Server, wie er deinen Bot startet.
btc-alert-bot / bot.pybtc-alert-bot / Procfile
Teil 4 · Railway

Schalte ihn ein und sieh zu, wie der Test-Alarm ankommt

  1. Registrier dich mit GitHubDie KI geht vorher die Preisseite von Railway mit dir durch.
  2. New Project, Deploy from GitHub repoWähl das Repository deines Bots.
  3. Trag deine Schlüssel in Variables einDeinen Token, deine Chat-ID und deinen KI-Schlüssel, den Coin, den du gewählt hast, und SEND_TEST_ON_START auf yes. Die KI listet alle auf. Danach löschst du sie aus deinen Notizen.
  4. Dein Test-Alarm kommt in Telegram anPrüf, ob die Logs alle 5 Minuten eine Preisprüfung zeigen, dann stell SEND_TEST_ON_START auf no.
Sicher aufbewahren

Deine Schlüssel liegen nur an einem Ort

  1. Der Variables-Bildschirm von RailwayNie im Code, nie auf GitHub, nie im Chat.
  2. Überall Zwei-Faktor-AnmeldungGitHub, Railway, Telegram und dein KI-Konto.
  3. Ein Schlüssel ist nach außen gelangt? Sperr ihnErstell einen neuen und füg ihn in Railway ein. Die KI zeigt dir für jeden Dienst, wie das geht.

Websites verschieben ihre Buttons. Wenn dein Bildschirm anders aussieht, sag der KI, was du siehst, dann arbeitet sie damit weiter.
