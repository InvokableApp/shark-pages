Guide d'installation

Installe ton bot d'alertes : Telegram, une clé d'IA, GitHub et Railway

Fais-le défiler sur ton téléphone, puis installe-toi devant ton ordinateur avec le prompt. L'IA te guide, ceci est la carte.

  • Navigateur uniquement
  • Sans coder
  • Environ 5 $ par mois
Ce qu'il te faut

Quatre comptes et une appli de notes

  1. TelegramSur ton téléphone. Gratuit.
  2. OpenAI ou AnthropicPour la ligne qui explique pourquoi ça a bougé. Quelques centimes par mois.
  3. GitHubStocke le code de ton bot. Gratuit.
  4. RailwayLe fait tourner jour et nuit. Environ 5 $ par mois après un crédit d'essai unique.

Ton appli de notes garde chaque clé quelques minutes, jusqu'à ce qu'elle aille dans Railway.

Partie 1 · Telegram

Crée ton bot et trouve ton chat id

  1. Ouvre @BotFatherEnvoie /newbot et choisis un nom. Il te donne un token : enregistre-le dans tes notes.
  2. Appuie sur Démarrer dans ton nouveau botUn bot ne peut pas t'écrire tant que tu ne l'as pas fait.
  3. Ouvre une adresse dans ton navigateurL'IA te la donne. Elle affiche ton chat id, un nombre. Enregistre-le aussi.

Cette adresse contient ton token. Ne la partage pas, ni une capture d'écran de celle-ci.

Partie 2 · Ta clé d'IA

Une seule clé, avec une limite de dépenses

  1. Crée un compte OpenAI ou AnthropicLes deux marchent. L'IA te dit où trouver la clé.
  2. Fixe une petite limite mensuelleLe bot ne l'interroge que quand une alerte se déclenche, quelques fois par mois.
  3. Enregistre la clé dans tes notesNe la colle jamais dans la conversation avec l'IA.
Partie 3 · GitHub

Deux fichiers dans un dépôt privé

  1. Crée un compte et active la connexion en deux étapesPuis un nouveau dépôt, réglé sur Private.
  2. Add file, Create new file : bot.pyColle le code que l'IA écrit pour toi et fais un commit.
  3. Un fichier de plus : ProcfileUne seule ligne dedans, worker: python3 bot.py. Il indique au serveur comment lancer ton bot.
btc-alert-bot / bot.pybtc-alert-bot / Procfile
Partie 4 · Railway

Lance-le et regarde l'alerte de test arriver

  1. Inscris-toi avec GitHubL'IA parcourt d'abord avec toi la page des tarifs de Railway.
  2. New Project, Deploy from GitHub repoChoisis le dépôt de ton bot.
  3. Ajoute tes clés dans VariablesTon token, ton chat id et ta clé d'IA, la crypto que tu as choisie, et SEND_TEST_ON_START réglé sur yes. L'IA te les liste toutes. Puis supprime-les de tes notes.
  4. Ton alerte de test arrive dans TelegramVérifie que les logs montrent une vérification du prix toutes les 5 minutes, puis règle SEND_TEST_ON_START sur no.
En sécurité

Tes clés vivent à un seul endroit

  1. L'écran Variables de RailwayJamais dans le code, jamais sur GitHub, jamais dans la conversation.
  2. Connexion en deux étapes partoutGitHub, Railway, Telegram et ton compte d'IA.
  3. Une clé a fuité ? Révoque-laCrée-en une nouvelle et colle-la dans Railway. L'IA te montre comment faire pour chaque service.
