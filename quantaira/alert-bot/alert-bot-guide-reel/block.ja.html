アラートボットの準備：Telegram、AIのキー、GitHub、Railway

まずスマホでスワイプして目を通し、それからプロンプトを持ってパソコンの前へ。 道案内はAIがしてくれます。これはその地図です。

  • ブラウザだけ
  • コーディング不要
  • 月5ドルほど
必要なもの

4つのアカウントとメモアプリ

  1. Telegramスマホに入れます。無料。
  2. OpenAIかAnthropic動いた理由をひとことで書くためのもの。月にごくわずかな費用です。
  3. GitHubボットのコードを置く場所。無料。
  4. Railwayボットを昼も夜も動かします。初回の無料トライアル分のあとは月5ドルほど。

それぞれのキーは、Railwayに入れるまでの数分間だけメモアプリに保管します。

パート1 · Telegram

ボットを作ってチャットIDを確認する

  1. @BotFatherを開く/newbotを送って名前を決めます。トークンがもらえるので、メモに保存しましょう。
  2. 作ったボットで「開始」をタップこれをしないと、ボットはあなたにメッセージを送れません。
  3. ブラウザでアドレスを1つ開くアドレスはAIが教えてくれます。あなたのチャットID（数字）が表示されるので、それも保存しましょう。

このアドレスにはあなたのトークンが含まれています。アドレスもスクリーンショットも人に見せないでください。

パート2 · AIのキー

キーは1つ。利用上限を設定しておきます

  1. OpenAIかAnthropicのアカウントを作るどちらでも大丈夫です。キーの場所はAIが教えてくれます。
  2. 少額の月間上限を設定するボットがAIを使うのはアラートが出るときだけ。月に数回程度です。
  3. キーをメモに保存するAIとのチャットには絶対に貼り付けないでください。
パート3 · GitHub

非公開リポジトリに2つのファイル

  1. アカウントを作り、二段階認証をオンにする次に新しいリポジトリを作り、Private（非公開）に設定します。
  2. Add file、Create new file：bot.pyAIが書いてくれたコードを貼り付けて、コミットします。
  3. もう1つのファイル：Procfile中身は1行だけ、worker: python3 bot.py。サーバーにボットの起動方法を伝えるファイルです。
btc-alert-bot / bot.pybtc-alert-bot / Procfile
パート4 · Railway

起動してテストのアラートが届くのを確認

  1. GitHubで登録する最初に、AIがRailwayの料金ページを一緒に確認してくれます。
  2. New Project、Deploy from GitHub repoボットのリポジトリを選びます。
  3. Variablesにキーを追加するトークン、チャットID、AIのキー、選んだコイン、そしてyesにしたSEND_TEST_ON_START。AIが全部リストにしてくれます。終わったらメモから削除しましょう。
  4. Telegramにテストのアラートが届くログに5分ごとの価格チェックが出ているのを確認したら、SEND_TEST_ON_STARTをnoにします。
安全に使うために

キーを置くのは1か所だけ

  1. RailwayのVariables画面コードにも、GitHubにも、チャットにも絶対に入れません。
  2. すべてで二段階認証GitHub、Railway、Telegram、そしてAIのアカウント。
  3. キーが漏れたら？無効にする新しいキーを作ってRailwayに貼り付けます。やり方はサービスごとにAIが教えてくれます。

ウェブサイトのボタンの位置は変わることがあります。画面が説明と違うときは、見えているものをAIに伝えれば、それに合わせて進めてくれます。
