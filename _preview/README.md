# _preview

Standalone review pages. NOT hosted blocks: nothing here is loaded by
`_loader`, referenced by a manifest, or installed into a GHL account. Each
folder is one self-contained `index.html` published so it can be opened on a
phone and reviewed before the design is cut into a real block.

Delete a folder once its design has shipped into `{system}/{funnel}/{page}/`.

| Folder | What it is |
|---|---|
| `glp-rep-hub` | Joe's home screen concept for the GLP rep hub: home plus funnel links, leads, how to promote, support. Videos and support urls not wired yet. |
